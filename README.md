# English Trip

Приложение для изучения английского с упором на понимание на слух. PWA: открывается по ссылке,
ставится на главный экран телефона и работает офлайн.

- Подробное описание проекта хранится у владельца локально
- Правила разработки: [CLAUDE.md](CLAUDE.md)

## Запуск

```bash
npm install
npm run dev
```
